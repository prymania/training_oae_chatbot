เทมเพลตโฟลเดอร์สำหรับเพิ่มเอกสารเข้าฐานความรู้
==============================================

วิธีใช้
  1. แตกไฟล์ ZIP นี้ออกมา
  2. วางไฟล์ PDF ลงในโฟลเดอร์หมวดย่อยที่ต้องการ
  3. กลับไปที่หน้าแอดมิน → ฐานความรู้ → เลือกโฟลเดอร์
     แล้วเลือกโฟลเดอร์ที่แตกออกมา (โฟลเดอร์นอกสุด)

โครงสร้าง
  <โดเมน>/<หมวดย่อย>/ไฟล์.pdf   → เข้าโดเมนและหมวดย่อยนั้น
  <โดเมน>/ไฟล์.pdf              → เข้าโดเมนนั้น หมวดย่อย 'ทั่วไป'

เพิ่มโดเมน / หมวดย่อยใหม่
  สร้างโฟลเดอร์ใหม่ได้เลย ระบบจะลงทะเบียนให้อัตโนมัติเมื่ออัปโหลด
  โฟลเดอร์ชั้นแรก = โดเมน, โฟลเดอร์ชั้นสอง = หมวดย่อย

ห้ามลบหรือเปลี่ยนชื่อ _TEMPLATE.json — ระบบใช้ไฟล์นี้จับคู่โฟลเดอร์
กับโดเมนเดิม ถ้าไม่มี ระบบจะเดาจากชื่อโฟลเดอร์แทน

โดเมนที่มีอยู่ตอนนี้
  - เนื้อโค: (ยังไม่มีหมวดย่อย)
  - ไก่: (ยังไม่มีหมวดย่อย)
  - โค: (ยังไม่มีหมวดย่อย)
  - ทุเรียน: (ยังไม่มีหมวดย่อย)
  - OAE สศก: (ยังไม่มีหมวดย่อย)
  - ปาล์มน้ำมัน: การจัดการฟาร์ม, การตลาด, ความเสี่ยง, ผลผลิต, ทั่วไป
  - ข้าว: (ยังไม่มีหมวดย่อย)
  - กุ้ง: (ยังไม่มีหมวดย่อย)
  - สุกร: (ยังไม่มีหมวดย่อย)
  - แมว: ทั่วไป
