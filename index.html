เอกสารอบรม oae-chatbot

เอกสาร OAE Chatbot แบ่งเป็น 3 พาร์ท



พาร์ท 1 🎓

เรียนรู้ระบบ LLM Chatbot

เรียนรู้ตั้งแต่การเตรียมเครื่อง ทดสอบ RAG ตามรอยการทำงานในโค้ด ทดลองสร้างแชทบอท LINE ไปจนถึงภาพรวมของระบบทั้งหมด

ไม่จำเป็นต้องมีพื้นฐานการเขียนโปรแกรมมาก่อน พาร์ท 2 🧑‍💻

โครงสร้างระบบ

ทำความเข้าใจโครงสร้างระบบ ไฟล์ ฟังก์ชัน และ API ที่สำคัญ ทดสอบการแก้ไขโค้ด frontend และ backend เพื่อให้สามารถพัฒนาต่อยอดระบบได้

สำหรับผู้ที่จะพัฒนาและดูแลระบบต่อ พาร์ท 3 🗂️

ดูแลระบบหลังบ้าน

เรียนรู้การใช้งานระบบหลังบ้าน ตั้งแต่การจัดการเอกสาร ผู้ใช้งาน และการดูข้อมูลต่าง ๆ โดยไม่ต้องเขียนโค้ด
